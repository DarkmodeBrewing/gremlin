# v0.1 Definition of Done audit

This audit maps the locked `docs/v0.1_spec.md` Definition of Done to concrete
repository or production evidence. M8 closes only missing release requirements;
it does not add new product scope.

## Product acceptance

| Requirement | Evidence | Status |
| --- | --- | --- |
| Raw conversations are persistently archived | `interactions` migration, REST integration coverage, and the production M7 source interaction | Verified |
| Multiple principals can ingest interactions | Principal-scoped ingestion plus Gremlin Chat and OpenCode integration coverage | Verified |
| Interactions retain source provenance | Authenticated principal is written as `source_principal`; request-supplied identity is rejected | Verified |

## M8 release gates

- [ ] Canonical interactions and events export as independently readable JSONL.
- [ ] Export preserves IDs, timestamps, source principals, content, and metadata.
- [ ] API-key rotation invalidates the old key and activates the replacement.
- [ ] Namespace-isolation failure cases pass for REST and MCP retrieval.
- [ ] A PostgreSQL backup is restored into a separate empty database and checked.
- [ ] Deployment, export, credential, backup, and recovery procedures are documented.
- [ ] Type checking, unit tests, PostgreSQL integration tests, and builds pass.
- [ ] The accepted merge commit is tagged `v0.1.0`.

## Explicit exclusions

M8 does not add import, scheduled consolidation, event consolidation, memory
mutation, reconstruction, OAuth, broader RBAC, or new integrations. Those
remain post-v0.1 work.
